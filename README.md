# 🚀 Open4K AI Upscaler

AI powered video enhancement tool that converts normal videos into high quality 4K videos using deep learning.

## ✨ Features

✅ Drag & Drop Video Upload  
✅ One Click 4K Upscaling  
✅ Real-ESRGAN AI Enhancement  
✅ Batch Frame Processing  
✅ Face Restoration Support (GFPGAN)  
✅ 60 FPS Smooth Motion Option  
✅ Google Colab GPU Support  
✅ FFmpeg Video Processing  
✅ Gradio Web Interface  


# 🧠 AI Models Used

## Real-ESRGAN

Used for:
- Video Super Resolution
- Detail Recovery
- Noise Reduction
- 4K Enhancement


## GFPGAN

Used for:
- Face Enhancement
- Portrait Restoration
- Old Video Improvement
